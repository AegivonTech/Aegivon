# Aegivon Technologies

Welcome to the Aegivon Technologies mono-repo!

This repository contains the main web presence for Aegivon, including our flagship safety intelligence platform, **Rakshak**.

## 🚀 Projects

- **`frontend/`** - The main Next.js App Router website, including the Aegivon corporate site and the Rakshak interactive product dossier.
- **`backend/`** - Node.js backend services and APIs.
- **`admin/`** - Administrative dashboards for managing platform data.

## 💻 Tech Stack (Frontend)

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **UI Library:** [React](https://reactjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** Custom CSS and Framer Motion

## 🛠️ Getting Started (Frontend)

To run the frontend locally:

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 🌐 Deployment

This project is fully configured and optimized for zero-config deployment on [Vercel](https://vercel.com). 

When importing the project in Vercel:
1. Select the `AegivonTech/Aegivon` repository.
2. Set the **Root Directory** to `frontend`.
3. Vercel will automatically detect the Next.js framework and configure the build settings.
